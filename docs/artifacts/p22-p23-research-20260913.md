## Q2: block-remainder split — one NEW candidate, one killed

Per-module split of the ~10%/phase remainder:

- `time_projection.1` (SiLU + Linear 1536→9216, f32): 322.9 ms over the
  4-chunk window (~80 ms/phase hook-basis) — the single largest
  non-attention, non-GEMM item. Upstream source proof
  (`model_fast.py:607-617`): `e0 = time_projection(e)`, `e` derived
  SOLELY from the timestep tensor `t` via sinusoidal embedding.
  Only 4 distinct `t` values exist per session (999/899/702 + clean 0),
  repeating every chunk and action. **Candidate: session-level memo of
  e0 keyed by timestep (exact replay, zero math change).**
- Camera path (`cam_*` ~62 ms/phase hook-basis): KILLED by source proof
  (`model_fast.py:298-301` + block forward): injector/scale/shift layers
  are PER-BLOCK weights — outputs differ per block, hoisting would
  change math. No GPU spent.
- Per-block modulation chunk (C6A candidate 2): re-confirmed dead
  (`model_fast.py` block forward: per-block `modulation` parameter).
