# Repository agent notes

DSH (`dsh-research-team`) may be used to run research campaigns against
this project, but this repository owns the authoritative LingRuntime
experiment state, DAG, and accepted evidence — not the research substrate
repository.

Before starting any LingRuntime work, read, in order:

1. `docs/lingruntime/RESEARCH_WORKFLOW.md` — ownership contract and
   multi-agent/worktree/GPU rules.
2. `docs/lingruntime/RESEARCH_AND_EXPERIMENT_DAG.md` — human-readable
   current DAG (what's done, running, blocked, and next).
3. `docs/lingruntime/lingruntime-dag.json` — machine-readable, authoritative
   current node status.
